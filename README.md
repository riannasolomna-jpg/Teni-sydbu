# Архив Дома — «Тени судьбы»

Первая рабочая версия публичной части сайта.

## Структура

- `index.html` — главная страница и оболочка сайта.
- `style.css` — оформление.
- `script.js` — навигация, категории, материалы и поиск.
- `lore/` — место для будущих файлов лора.
- `images/` — изображения по разделам.
- `posts/` — заготовка под будущую систему хранения материалов.

## Сейчас

Материалы для демонстрации находятся прямо в `script.js` в массиве `POSTS`.

Позже их можно вынести в отдельные JSON/Markdown-файлы или подключить к безопасной админке. Секретные GitHub-токены нельзя помещать в клиентский JavaScript.

## Публикация

Репозиторий можно опубликовать через GitHub Pages. Для настоящей админки потребуется отдельный безопасный серверный механизм; GitHub Pages сам по себе не принимает и не сохраняет данные из админской формы.
